# 📚 Library Management System

## 1. Project Overview

The Library Management System is a web-based application developed to manage library books efficiently.

The application allows users to add, view, update, delete, and search book records. It provides a simple and responsive interface using HTML, CSS, and JavaScript.

This project demonstrates the basic CRUD (Create, Read, Update, Delete) operations required for a web application.

---

## 2. Problem Statement

Managing library book records manually can be time-consuming and may lead to errors or duplicate records.

The Library Management System provides a simple digital solution for maintaining book information and performing CRUD operations efficiently.

---

## 3. Objectives

- To develop a simple Library Management System.
- To implement CRUD operations.
- To provide an easy-to-use user interface.
- To add, view, edit, and delete book records.
- To implement book search functionality.
- To perform client-side form validation.
- To store book data using browser local storage.
- To create a responsive web application.

---

## 4. Features

### ➕ Create

Users can add new books by entering:

- Book Title
- Author
- ISBN
- Category
- Quantity

### 📖 Read

Users can view all available books in a table.

### ✏️ Update

Users can edit existing book information.

### 🗑️ Delete

Users can delete a book record after confirmation.

### 🔍 Search

Users can search books using:

- Book title
- Author name
- ISBN

### ✅ Validation

The application checks:

- Required fields
- Quantity value
- Duplicate ISBN
